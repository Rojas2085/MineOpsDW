# Definition of Done

Una tarea se considera terminada solo si:
- [x] cumple criterios de aceptación de la fase;
- [x] tiene pruebas adecuadas;
- [x] se ejecutaron pruebas y se reportan resultados reales;
- [x] errores y limitaciones conocidos están documentados;
- [x] logs y UI diferencian real/estimado/no disponible/simulado;
- [x] no se introdujeron secretos ni datos locales en Git;
- [x] no se añadieron dependencias sin justificar;
- [x] se revisó `git diff`;
- [x] documentación y ejemplos están actualizados;
- [x] se detuvo el trabajo para revisión del usuario antes de la siguiente fase.
