# Definition of Done

Una tarea se considera terminada solo si:
- [ ] cumple criterios de aceptación de la fase;
- [ ] tiene pruebas adecuadas;
- [ ] se ejecutaron pruebas y se reportan resultados reales;
- [ ] errores y limitaciones conocidos están documentados;
- [ ] logs y UI diferencian real/estimado/no disponible/simulado;
- [ ] no se introdujeron secretos ni datos locales en Git;
- [ ] no se añadieron dependencias sin justificar;
- [ ] se revisó `git diff`;
- [ ] documentación y ejemplos están actualizados;
- [ ] se detuvo el trabajo para revisión del usuario antes de la siguiente fase.
